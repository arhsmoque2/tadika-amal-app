📱 Kelebihan Stack Vue 3 + Inertia.js (Mobile-First)

Inertia v2 + Vue 3 SPA

Ibu bapa dan penjaga mengakses aplikasi 95% melalui telefon pintar. Antaramuka Vue 3 + Inertia.js memberikan pengalaman Progressive Web App (PWA) yang sangat pantas seperti aplikasi native tanpa perlu muat turun dari App Store / Google Play.

  • ✨ Zero Page Refresh: Pertukaran skrin antara status anak, semakan buku rekod, dan galeri foto berlaku sekelip mata.
  • 📲 Touch-Optimized Gestures: Carousel gambar aktiviti, pull-to-refresh log hafazan, dan slide-up drawer bayaran.
  • 💬 WhatsApp & FPX Integration: Pembayaran yuran terus buka ToyyibPay / Billplz / DuitNow QR dengan resit PDF automatik.

Perbandingan 3 Pilihan Stack untuk Tadika Amal Apps

Cadangan penyelesaian berdasarkan penemuan repo ARH-Baca & keperluan sekolah tadika / prasekolah.

Pilihan A

Laravel 12 + Filament v4

Multi-Panel Native PHP (Admin, Guru, Penjaga)

  • ⚡ Paling pantas dibina & siap (100% PHP, tiada Node runtime complex).
  • 🛡️ Filament Shield Role-Based Access sedia ada (Superadmin, Guru Besar, Guru Kelas, Ibu Bapa).
  • 📊 Sangat kuat untuk modul jadual data, invois yuran pukal, & eksport PDF/Excel.
  • ⚠️ Pengalaman mobile ibu bapa berasaskan web view (perlu plugin filament-mobile-preset).
Kesesuaian: 88% Paling Pantas
Pilihan B

Laravel 12 + Inertia.js + Vue 3

Single Page Application (SPA) + Tailwind v4

  • 📱 Pengalaman mobile ibu bapa bertaraf 5 bintang (PWA, gesture, fluid animation).
  • 🎨 Fleksibiliti 100% mereka bentuk antaramuka khas mengikut identiti Tadika Amal.
  • ⚡ Prestasi UI sangat responsif tanpa reload halaman.
  • ⏳ Memerlukan masa membina komponen form & table dari sifar berbanding Filament.
Kesesuaian: 92% UI Terbaik
⭐ Disyorkan (Best of Both)
Pilihan C (Hibrid)

Filament v4 (Admin & Guru) + Vue 3 Inertia (Ibu Bapa PWA)

Dwi-Antaramuka Dioptimumkan Mengikut Peranan

  • 🏆 Guru Besar & Pentadbir mendapat kuasa penuh Filament v4 untuk data berat, yuran, dan laporan audit.
  • 📱 Ibu Bapa mendapat Web App Vue 3 yang anggun, mesra telefon pintar untuk memantau anak dan membayar yuran.
  • 🔄 Kongsi pangkalan data & logic Eloquent yang sama 100%.
Kesesuaian: 98% Pilihan Unggul

📦 Modul Utama Tadika Amal (Database Schema Blueprint)

👶

1. Pengurusan Murid & Kelas

Pendaftaran, kelas mengikut umur (4/5/6 Tahun), maklumat kesihatan & alahan, kebenaran penjaga mengambil anak.

📖

2. Rekod Huffaz & Iqra'

Penjejak jilid Iqra' (1-6) dan surah hafazan harian (Juz Amma), rekod solat harian, catatan makhraj oleh guru.

⏱️

3. Kehadiran & Kiosk Pagi

Imbas QR / Kod Murid semasa tiba, rekod suhu badan, catatan kesihatan, notifikasi segera ke WhatsApp ibu bapa.

💳

4. Yuran & Pembayaran

Penjanaan invois automatik awal bulan, integrasi FPX (ToyyibPay/Billplz), resit rasmi PDF, pengesanan tunggakan.

📸

5. Diari Harian & Galeri

Guru memuat naik gambar aktiviti harian, menu makan tengah hari, waktu tidur siang, dan pencapaian mingguan.

📢

6. Hebahan & Komunikasi

Papan kenyataan digital, takwim cuti sekolah & aktiviti, hebahan kecemasan melalui WhatsApp Cloud API.
